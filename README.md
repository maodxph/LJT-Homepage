# LJT-Homepage

Personal academic homepage of **Junteng Liu**, a first-year PhD candidate at the HKUST NLP Group, Hong Kong University of Science and Technology.

The site is built with [Jekyll](https://jekyllrb.com) and is based on the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template.

## Structure

* `_pages/about.md` &ndash; homepage: about me, research interests, education, research experience, publications, skills, honors and contact information
* `_pages/publications.html` &ndash; publication list page
* `_publications/` &ndash; one Markdown file per publication
* `_config.yml` &ndash; site and author settings
